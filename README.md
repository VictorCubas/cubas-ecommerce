# Tu Ticket Point 🛒

Este proyecto fue realizado para aprender las bases de react con javascript

![image](/public/tuticketpoint.png)


### Instalación ⚙️

1. Clone el repositorio
2. Haga el comando `cd coder-flex-app` para moverse a la carpeta del proyecto
3. Instale dependencias ejecutando `npm install`
4. Para levantar la app en servidor local ejecute `npm run dev`

### Version HOST 💻

Si desea ver el proyecto online, puede ingresar al siguiente link: [Coder Flex App]()

### Librerias Utilizadas 📖

- [Material Tailwind React](https://www.material-tailwind.com/): utilizada para el styling de la app
- [Firebsae](https://console.firebase.google.com/): utilizada como base de datos
- [React Router Dom](https://reactrouter.com/home/): utilizada para la navegacion por rutas
- [React Hot Toast](https://react-hot-toast.com/): para mostrar mensajes de exito o error
